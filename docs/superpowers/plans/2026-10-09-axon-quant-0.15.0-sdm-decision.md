# axon_quant 0.15.0 SDM 决策层下沉 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 `axon-llm` crate 内新增 `decision` 子模块，提供 `DecisionBackend` trait + stub/replay/http 三实现 + 置信门控 cascade（含 LLM 兜底融合），并通过 PyO3 暴露为 `_native.llm.decision`。

**Architecture:** 行为以 QuantCell `backend/decision/`（types/client/cascade/questions 的 fingerprint 部分）为权威移植来源；`state` 保持 `serde_json::Value` 不解释，`questions/answers` 强类型化对齐 SDM 协议。核心零网络依赖（`decision` feature，仅用已存在的 sha2/hex optional dep），真实 HTTP 走 `decision-http`（复用 `backends` 的 `with_backoff`）。不改 QuantCell。

**Tech Stack:** Rust 2021 / tokio / async-trait / serde / serde_json / sha2 / hex / reqwest（feature 门控）/ PyO3 0.28 + pyo3-async-runtimes / wiremock（e2e）。

**Spec:** `docs/superpowers/specs/2026-10-09-axon-quant-0.15.0-sdm-decision-design.md`

**分支/版本前置（已完成）：** 当前分支 `0.15.0`；`Cargo.toml`/`pyproject.toml`/`Cargo.lock` 已为 0.15.0；CHANGELOG 0.15.0 节已写。

**与 spec 的两处实现细化（YAGNI，不改变验收标准）：**
1. **cost 不接 `backends::cost`**：SDM 响应 `usage` 自带 `cost_usd`（与 LLM 按 token 定价不同），直接透传即可，无需 token→USD 表。
2. **HTTP 录制不接 `backends::recording`**：离线重放由 `ReplayDecisionBackend`（JSONL + 指纹）完整覆盖；HTTP 录制中间件是后续优化，本版本不做。

**提交信息语言：** axon_quant 仓库规则要求英文 commit message，全部使用 `feat:`/`test:`/`chore:` 前缀。

```rust
//! SDM 决策后端抽象与统一错误类型

/// SDM 决策调用的统一错误类型
#[derive(Debug, thiserror::Error)]
pub enum DecisionError {
    /// 网络错误（瞬时，可重试）
    #[error("network error: {0}")]
    Network(String),

    /// 认证失败（不可重试）
    #[error("auth error: {0}")]
    Auth(String),

    /// 限流（携带服务端 Retry-After 秒数，可空）
    #[error("rate limited (retry_after={retry_after:?}s)")]
    RateLimited {
        /// 服务端建议等待秒数，未知为 None
        retry_after: Option<u64>,
    },

    /// 响应解析失败（不可重试）
    #[error("parse error: {0}")]
    Parse(String),

    /// 后端通用错误（含 replay miss；5xx 可重试）
    #[error("backend error: {0}")]
    Backend(String),
}

impl DecisionError {
    /// 是否值得重试，与 `LLMError::is_retryable` 口径一致
    pub fn is_retryable(&self) -> bool {
        matches!(
            self,
            Self::Network(_) | Self::RateLimited { .. } | Self::Backend(_)
        )
    }

    /// 错误判别名（用于 cascade 写 fallback_reason，不对外暴露内部结构）
    pub fn kind(&self) -> &'static str {
        match self {
            Self::Network(_) => "Network",
            Self::Auth(_) => "Auth",
            Self::RateLimited { .. } => "RateLimited",
            Self::Parse(_) => "Parse",
            Self::Backend(_) => "Backend",
        }
    }
}

#[cfg(test)]
mod tests {
    use super::*;

    #[test]
    fn retryable_matches_llm_error_policy() {
        assert!(DecisionError::Network("x".into()).is_retryable());
        assert!(DecisionError::RateLimited { retry_after: None }.is_retryable());
        assert!(DecisionError::Backend("5xx".into()).is_retryable());
        assert!(!DecisionError::Auth("bad key".into()).is_retryable());
        assert!(!DecisionError::Parse("bad json".into()).is_retryable());
    }

    #[test]
    fn kind_names_are_stable() {
        assert_eq!(DecisionError::Network("x".into()).kind(), "Network");
        assert_eq!(DecisionError::Parse("x".into()).kind(), "Parse");
        assert_eq!(
            DecisionError::RateLimited { retry_after: Some(2) }.kind(),
            "RateLimited"
        );
    }
}
```

```rust
//! SDM 决策协议类型
//!
//! 字段名严格对齐 SDM 协议（`type/instructions/criteria`；
//! 答案 `noul/choice/score/confidence/probabilities`），录制 JSON 与真实响应零转换。
//! [`CascadeDecision`] 是 cascade 所有分支的唯一返回类型。

use std::collections::BTreeMap;

use serde::{Deserialize, Serialize};

use super::backend::DecisionError;

/// 三种交易动作；概率 dict 的键恒为这三个
#[derive(Debug, Clone, Copy, PartialEq, Eq, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Action {
    /// 做多
    Buy,
    /// 做空
    Sell,
    /// 观望
    Hold,
}

impl Action {
    /// 协议字符串
    pub fn as_str(&self) -> &'static str {
        match self {
            Action::Buy => "buy",
            Action::Sell => "sell",
            Action::Hold => "hold",
        }
    }

    /// 从协议字符串解析
    pub fn from_name(s: &str) -> Option<Self> {
        Some(match s {
            "buy" => Action::Buy,
            "sell" => Action::Sell,
            "hold" => Action::Hold,
            _ => return None,
        })
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]

#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct ChoiceInstructions {

    pub question: String,
    /// 关注点
    pub focus: String,
}

/// choice 问题单个选项的判定标准
#[derive(Debug, Clone, PartialEq, Eq, Serialize, Deserialize)]
pub struct Criterion {
    /// 该选项的描述
    pub what: String,
}

/// 决策问题（内部 tag = `type`）
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum Question {
    /// 是/否命题
    Noul {
        /// 命题说明
        instructions: String,
    },
    /// 有界单选
    Choice {
        /// 问题说明（对象）
        instructions: ChoiceInstructions,
        /// 各选项标准
        criteria: BTreeMap<String, Criterion>,
    },
    /// 有序量表
    Score {
        /// 问题说明（字符串）
        instructions: String,
        /// 各等级描述（索引即等级）
        criteria: Vec<String>,
    },
}

/// 单个问题的答案（内部 tag = `type`，结构体变体保证 serde 稳定）
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
#[serde(tag = "type", rename_all = "snake_case")]
pub enum Answer {
    /// 是/否命题：noul 为命题成立的校准概率 0–1
    Noul {
        /// 命题成立概率
        noul: f64,
    },
    /// 有界单选：胜选项 + 校准置信 + 全选项概率分布
    Choice {
        /// 胜选项
        choice: String,
        /// 校准置信度
        confidence: f64,
        /// 全选项概率
        probabilities: BTreeMap<String, f64>,
    },
    /// 有序量表：概率加权等级 + 各等级概率
    Score {
        /// 概率加权得分
        score: f64,
        /// 置信度
        confidence: f64,
        /// 各等级概率
        probabilities: BTreeMap<String, f64>,
    },
}

/// 决策请求；state 为领域自定义 JSON，decision 层不解释
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct DecisionRequest {
    /// 领域状态（含 features/window 等）
    pub state: serde_json::Value,
    /// 类型化问题表
    pub questions: BTreeMap<String, Question>,
}

/// SDM 单次响应
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct DecisionResponse {
    /// 模型标识
    pub model: String,
    /// 各问题答案
    pub answers: BTreeMap<String, Answer>,
    /// 计费信息
    pub usage: DecisionUsage,
}

impl DecisionResponse {
    /// 从原始 JSON 解析；缺字段/未知类型返回 [`DecisionError::Parse`]，不做静默兜底
    pub fn from_value(v: serde_json::Value) -> Result<Self, DecisionError> {
        serde_json::from_value(v).map_err(|e| DecisionError::Parse(e.to_string()))
    }
}

/// cascade 统一出口（直出/低置信/异常三分支同构）
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct CascadeDecision {
    /// 最终动作
    pub action: Action,
    /// 来源
    pub source: DecisionSource,
    /// 置信度
    pub confidence: f64,
    /// buy/sell/hold 三键恒在
    pub probabilities: BTreeMap<String, f64>,
    /// source=Fallback 时必填原因
    pub fallback_reason: Option<String>,
    /// SDM 计费（异常未拿到响应时为 None）
    pub sdm_usage: Option<DecisionUsage>,
    /// 子问题信号，仅归因，禁止参与门控
    pub sub_signals: BTreeMap<String, f64>,
}
```

```rust
//! 请求规范化与指纹：Replay 后端的精确匹配键（跨语言单一真源）
//!
//! canonical = 紧凑 JSON（键排序来自 BTreeMap、无空格、UTF-8 原文），
//! 与 QuantCell `json.dumps(ensure_ascii=False, sort_keys=True, separators=(',',':'))` 等价。

use sha2::{Digest, Sha256};

use super::types::DecisionRequest;

/// 规范化请求体（紧凑、键有序、UTF-8）
pub fn canonical_request(req: &DecisionRequest) -> String {
    // DecisionRequest 仅含 Value/BTreeMap/字符串/数字，序列化不可能失败
    serde_json::to_string(req).expect("decision request is always serializable")
}

/// 请求指纹（sha256 hex）
pub fn request_fingerprint(req: &DecisionRequest) -> String {
    let mut hasher = Sha256::new();
    hasher.update(canonical_request(req).as_bytes());
    hex::encode(hasher.finalize())
}
```

```rust
fn softmax(values: [f64; 3]) -> [f64; 3] {
    let top = values[0].max(values[1]).max(values[2]);
    let exps = values.map(|v| (v - top).exp());
    let total: f64 = exps.iter().sum();
    exps.map(|v| v / total)
}

fn sigmoid(x: f64) -> f64 {
    1.0 / (1.0 + (-x).exp())
}

fn clamp(x: f64, lo: f64, hi: f64) -> f64 {
    lo.max(hi.min(x))
}

fn round6(x: f64) -> f64 {
    (x * 1e6).round() / 1e6

        .get("features")

        for idx in [lower, upper] {

            score_probs.insert(idx.to_string(), json!(cur + 0.1));
```

```rust
//! 指纹精确回放后端：fingerprint → 录制响应；miss 即报错（禁止静默兜底）

use std::collections::BTreeMap;
use std::path::Path;

use super::types::{DecisionRequest, DecisionResponse};

/// 回放后端模型标识

/// 指纹 → 录制响应 的精确回放
pub struct ReplayDecisionBackend {
    recordings: BTreeMap<String, DecisionResponse>,
}

impl ReplayDecisionBackend {
    /// 从内存映射构造
    pub fn new(recordings: BTreeMap<String, DecisionResponse>) -> Self {
        Self { recordings }
    }

    /// 读取 JSONL，每行形如 {"fingerprint": "...", "response": {...}}
    pub fn from_jsonl(path: &Path) -> std::io::Result<Self> {
        let content = std::fs::read_to_string(path)?;
        let mut recordings = BTreeMap::new();
        for (lineno, line) in content.lines().enumerate() {
            let line = line.trim();
            if line.is_empty() {
                continue;
            }
            let v: serde_json::Value = serde_json::from_str(line).map_err(|e| {
                std::io::Error::new(
                    std::io::ErrorKind::InvalidData,
                    format!("line {}: {e}", lineno + 1),
                )
            })?;
            let fp = v
                .get("fingerprint")
                .and_then(|x| x.as_str())
                .ok_or_else(|| {
                    std::io::Error::new(
                        std::io::ErrorKind::InvalidData,
                        format!("line {}: missing fingerprint", lineno + 1),
                    )
                })?;
            let resp_v = v.get("response").cloned().ok_or_else(|| {
                std::io::Error::new(
                    std::io::ErrorKind::InvalidData,
                    format!("line {}: missing response", lineno + 1),
                )
            })?;
            let resp = DecisionResponse::from_value(resp_v).map_err(|e| {
                std::io::Error::new(std::io::ErrorKind::InvalidData, e.to_string())
            })?;
            recordings.insert(fp.to_string(), resp);
        }
        Ok(Self { recordings })
    }

    /// 录制条数
    pub fn len(&self) -> usize {
        self.recordings.len()
    }

    /// 是否为空
    pub fn is_empty(&self) -> bool {
        self.recordings.is_empty()
    }
}

#[async_trait]
impl DecisionBackend for ReplayDecisionBackend {
    async fn decide(&self, req: &DecisionRequest) -> Result<DecisionResponse, DecisionError> {
        let fp = request_fingerprint(req);
        self.recordings
            .get(&fp)
            .cloned()
            .ok_or_else(|| DecisionError::Backend(format!("replay miss for fingerprint={fp}")))
    }

    fn model_name(&self) -> &str {
        REPLAY_MODEL
    }
}
```

- [ ] **Step 1: 创建 cascade.rs（含内联测试）**

创建 `crates/axon-llm/src/decision/cascade.rs`：
```rust
//! REFLEX 置信门控级联：SDM 直出 → 低置信兜底 → 异常兜底
//!
//! 硬约束：
//! - 三条路径返回同一个 [`CascadeDecision`]，不早退裸结构。
//! - 门控只使用 SDM 原始校准 confidence，不组合综合分。
//! - 低置信与异常都已耗费一次调用（异常可能未计费），usage 如实透传或置 None。

use std::collections::BTreeMap;
use std::sync::Arc;

use async_trait::async_trait;

use super::backend::{DecisionBackend, DecisionError};
use super::types::{
    Action, Answer, CascadeDecision, DecisionRequest, DecisionResponse, DecisionSource,
    DecisionUsage,
};

/// 动作键固定顺序
pub const ACTIONS: [&str; 3] = ["buy", "sell", "hold"];

/// 非对称门控：开仓阈值高于观望阈值（开仓判错代价更高）
#[derive(Debug, Clone, Copy, PartialEq)]
pub struct CascadeConfig {
    /// buy/sell 放行阈值
    pub open_threshold: f64,
    /// hold 放行阈值
    pub hold_threshold: f64,
}

impl Default for CascadeConfig {
    fn default() -> Self {
        Self {
            open_threshold: 0.80,
            hold_threshold: 0.70,
        }
    }
}

/// 置信度是否达到该动作的放行阈值（边界值放行）
pub fn gate_allows(action: Action, confidence: f64, config: &CascadeConfig) -> bool {
    let threshold = match action {
        Action::Buy | Action::Sell => config.open_threshold,
        Action::Hold => config.hold_threshold,
    };
    confidence >= threshold
}

/// 兜底决策协议
#[async_trait]
pub trait FallbackDecider: Send + Sync {
    /// 返回 (动作, buy/sell/hold 概率分布, 置信度)
    async fn decide(
        &self,
        state: &serde_json::Value,
    ) -> Result<(Action, BTreeMap<String, f64>, f64), DecisionError>;
}

/// 确定性规则兜底：双均线偏离与近一根收益同向才开仓，否则 hold
pub struct RuleFallback;

impl RuleFallback {
    /// 构造
    pub fn new() -> Self {
        Self
    }
}

impl Default for RuleFallback {
    fn default() -> Self {
        Self::new()
    }
}

#[async_trait]
impl FallbackDecider for RuleFallback {
    async fn decide(
        &self,
        state: &serde_json::Value,
    ) -> Result<(Action, BTreeMap<String, f64>, f64), DecisionError> {
        let feat = |name: &str| -> Result<f64, DecisionError> {
            state
                .get("features")
                .and_then(|f| f.get(name))
                .and_then(|v| v.as_f64())
                .ok_or_else(|| DecisionError::Backend(format!("features.{name} missing")))
        };
        let sma = feat("sma5_vs_sma20")?;
        let ret = feat("ret_1")?;
        let action = if sma > 0.0 && ret > 0.0 {
            Action::Buy
        } else if sma < 0.0 && ret < 0.0 {
            Action::Sell
        } else {
            Action::Hold
        };
        let mut probs = BTreeMap::new();
        let (win, other) = (0.7_f64, 0.1_f64);
        match action {
            Action::Buy => {
                probs.insert("buy".to_string(), win);
                probs.insert("sell".to_string(), other);
                probs.insert("hold".to_string(), 0.2);
            }
            Action::Sell => {
                probs.insert("sell".to_string(), win);
                probs.insert("buy".to_string(), other);
                probs.insert("hold".to_string(), 0.2);
            }
            Action::Hold => {
                probs.insert("hold".to_string(), 0.5);
                probs.insert("buy".to_string(), 0.25);
                probs.insert("sell".to_string(), 0.25);
            }
        }
        let confidence = probs[action.as_str()];
        Ok((action, probs, confidence))
    }
}

/// 提取 3 个并行子问题信号；仅离线归因，禁止参与门控
fn extract_sub_signals(resp: &DecisionResponse) -> BTreeMap<String, f64> {
    let mut sub = BTreeMap::new();
    if let Some(Answer::Noul { noul }) = resp.answers.get("trend_confirms") {
        sub.insert("trend_confirms".to_string(), *noul);
    }
    if let Some(Answer::Noul { noul }) = resp.answers.get("risk_regime_bad") {
        sub.insert("risk_regime_bad".to_string(), *noul);
    }
    if let Some(Answer::Score { score, .. }) = resp.answers.get("signal_clarity") {
        sub.insert("signal_clarity".to_string(), *score);
    }
    sub
}

/// 补齐 buy/sell/hold 三键；保持原始概率不归一化（校准值不可篡改）
fn ensure_action_keys(probs: &BTreeMap<String, f64>) -> BTreeMap<String, f64> {
    ACTIONS
        .iter()
        .map(|name| (*name, probs.get(*name).copied().unwrap_or(0.0)))
        .map(|(k, v)| (k.to_string(), v))
        .collect()
}

/// SDM（快决策）+ 兜底的级联层，返回统一出口
pub struct SdmCascadeDecisionLayer {
    backend: Arc<dyn DecisionBackend>,
    fallback: Arc<dyn FallbackDecider>,
    config: CascadeConfig,
}

impl SdmCascadeDecisionLayer {
    /// 构造
    pub fn new(
        backend: Arc<dyn DecisionBackend>,
        fallback: Arc<dyn FallbackDecider>,
        config: CascadeConfig,
    ) -> Self {
        Self {
            backend,
            fallback,
            config,
        }
    }

    /// 执行级联决策
    pub async fn decide(&self, req: &DecisionRequest) -> CascadeDecision {
        // 路径一：SDM 调用异常（网络/解析/replay miss），未拿到有效响应
        let resp = match self.backend.decide(req).await {
            Ok(r) => r,
            // ponytail: 兜底面收到宽到 DecisionError 全集，任何 SDM 侧失败都不能让交易循环崩掉；
            // 升级路径是按错误类型细分重试/熔断，当前阶段无此需求
            Err(e) => {
                return self
                    .use_fallback(
                        req,
                        format!("sdm_error: {}", e.kind()),
                        None,
                        BTreeMap::new(),
                    )
                    .await;
            }
        };

        let sub_signals = extract_sub_signals(&resp);
        let usage = resp.usage;

        // 路径二：响应结构无法支撑门控（主问题缺失/类型错/胜选项不在动作集）。
        // 一次性解构出（动作, 置信度, 概率分布）；概率需 clone 以构造 owned 出口。
        let (action, confidence, probabilities) = match resp.answers.get("next_direction") {
            Some(Answer::Choice {
                choice,
                confidence,
                probabilities,
            }) if Action::from_name(choice).is_some() => (
                Action::from_name(choice).expect("checked above"),
                *confidence,
                probabilities.clone(),
            ),
            _ => {
                return self
                    .use_fallback(
                        req,
                        "sdm_error: invalid_choice".to_string(),
                        Some(usage),
                        sub_signals,
                    )
                    .await;
            }
        };

        // 路径三：校准置信度未达非对称阈值
        if !gate_allows(action, confidence, &self.config) {
            return self
                .use_fallback(
                    req,
                    format!("low_confidence: {}={}", action.as_str(), confidence),
                    Some(usage),
                    sub_signals,
                )
                .await;
        }

        // 直出：概率只补缺键不归一化，保留 SDM 原始校准分布
        CascadeDecision {
            action,
            source: DecisionSource::SdmDirect,
            confidence,
            probabilities: ensure_action_keys(&probabilities),
            fallback_reason: None,
            sdm_usage: Some(usage),
            sub_signals,
        }
    }

    /// 走兜底；兜底自身失败时降级为安全 Hold，保证任何分支都返回合法结构
    async fn use_fallback(
        &self,
        req: &DecisionRequest,
        reason: String,
        usage: Option<DecisionUsage>,
        sub_signals: BTreeMap<String, f64>,
    ) -> CascadeDecision {
        match self.fallback.decide(&req.state).await {
            Ok((action, probabilities, confidence)) => CascadeDecision {
                action,
                source: DecisionSource::Fallback,
                confidence,
                probabilities,
                fallback_reason: Some(reason),
                sdm_usage: usage,
                sub_signals,
            },
            Err(e) => {
                let mut probabilities = BTreeMap::new();
                probabilities.insert("hold".to_string(), 1.0);
                probabilities.insert("buy".to_string(), 0.0);
                probabilities.insert("sell".to_string(), 0.0);
                CascadeDecision {
                    action: Action::Hold,
                    source: DecisionSource::Fallback,
                    confidence: 0.0,
                    probabilities,
                    fallback_reason: Some(format!("fallback_error: {}", e.kind())),
                    sdm_usage: usage,
                    sub_signals,
                }
            }
        }
    }
}
```

```rust
                .to_string(),

        }

/// LLMError → DecisionError（语义对齐）
pub(crate) fn map_llm_error(e: LLMError) -> DecisionError {
    match e {
        LLMError::Network(m) => DecisionError::Network(m),
        LLMError::Auth(m) => DecisionError::Auth(m),
        LLMError::RateLimited { retry_after } => DecisionError::RateLimited { retry_after },
        LLMError::Parse(m) => DecisionError::Parse(m),
        LLMError::ContextOverflow { needed, limit } => {
            DecisionError::Backend(format!("context window overflow: {needed} > {limit}"))
        }
        LLMError::MockExhausted => DecisionError::Backend("mock backend exhausted".into()),
        LLMError::Backend(m) => DecisionError::Backend(m),
    }
}

/// 从 LLM 文本中抽取 JSON 并解析为 (动作, 三键概率, 置信度)
pub(crate) fn parse_llm_content(content: &str) -> Result<(Action, BTreeMap<String, f64>, f64), DecisionError> {
    let start = content.find('{').ok_or_else(|| DecisionError::Parse("no json object".into()))?;
    let end = content
        .rfind('}')
        .ok_or_else(|| DecisionError::Parse("no json object".into()))?;
    if end < start {
        return Err(DecisionError::Parse("malformed json object".into()));
    }
    let v: serde_json::Value = serde_json::from_str(&content[start..=end])
        .map_err(|e| DecisionError::Parse(e.to_string()))?;
    let action = v
        .get("action")
        .and_then(|x| x.as_str())
        .and_then(Action::from_name)
        .ok_or_else(|| DecisionError::Parse("missing/invalid action".into()))?;
    let confidence = v
        .get("confidence")
        .and_then(|x| x.as_f64())
        .unwrap_or(0.0)
        .clamp(0.0, 1.0);
    // 胜选项给置信度，其余概率均分剩余质量，保证三键齐全且和为 1
    let rest = (1.0 - confidence).max(0.0) / 2.0;
    let mut probs = BTreeMap::new();
    for name in ["buy", "sell", "hold"] {
        probs.insert(name.to_string(), if Action::from_name(name) == Some(action) { confidence } else { rest });
    }
    Ok((action, probs, confidence))
}

#[async_trait]
impl FallbackDecider for LlmFallback {
    async fn decide(
        &self,
        state: &serde_json::Value,
    ) -> Result<(Action, BTreeMap<String, f64>, f64), DecisionError> {
        let state_str = state.to_string();
        let vars = HashMap::from([("state", state_str.as_str())]);
        let user = self.prompt.render_user(&vars);
        let messages = vec![
            Message::system(self.prompt.system_with_few_shot()),
            Message::user(user),
        ];
        let resp = self.backend.complete(&messages).await.map_err(map_llm_error)?;
        let content = resp
            .content
            .ok_or_else(|| DecisionError::Parse("llm returned empty content".into()))?;
        parse_llm_content(&content)
    }
}
```

```rust
#[derive(Debug, Clone)]

/// SDM 真实 HTTP 后端
pub struct SdmHttpBackend {
    client: reqwest::Client,
    cfg: SdmHttpConfig,
}

impl SdmHttpBackend {
    /// 构造（构建 client 失败返回 Network 错误）
    pub fn new(cfg: SdmHttpConfig) -> Result<Self, DecisionError> {
        let client = reqwest::Client::builder()
            .timeout(Duration::from_secs(cfg.timeout_secs.max(1)))
            .build()
            .map_err(|e| DecisionError::Network(e.to_string()))?;
        Ok(Self { client, cfg })
    }

    fn url(&self) -> String {
        format!(
            "{}/v1/decide",
            self.cfg.base_url.trim_end_matches('/')
        )
    }
}

fn status_to_llm_error(status: u16, body: String) -> LLMError {
    match status {
        401 | 403 => LLMError::Auth(body),
        429 => LLMError::RateLimited { retry_after: None },
        s if (500..600).contains(&s) => LLMError::Backend(body),
        _ => LLMError::Backend(format!("unexpected status {s}: {body}")),
    }
}

#[async_trait]
impl DecisionBackend for SdmHttpBackend {
    async fn decide(&self, req: &DecisionRequest) -> Result<DecisionResponse, DecisionError> {
        let url = self.url();
        let body = serde_json::json!({
            "model": self.cfg.model,
            "state": req.state,
            "questions": req.questions,
        });
        let backoff = BackoffConfig {
            max_retries: self.cfg.max_retries,
            ..BackoffConfig::default()
        };
        let text: String = with_backoff(backoff, || {
            let client = self.client.clone();
            let url = url.clone();
            let key = self.cfg.api_key.clone();
            let body = body.clone();
            async move {
                let resp = client
                    .post(&url)
                    .bearer_auth(key)
                    .json(&body)
                    .send()
                    .await
                    .map_err(|e| LLMError::Network(e.to_string()))?;
                let status = resp.status().as_u16();
                let text = resp
                    .text()
                    .await
                    .map_err(|e| LLMError::Network(e.to_string()))?;
                if status == 200 {
                    Ok(text)
                } else {
                    Err(status_to_llm_error(status, text))
                }
            }
        })
        .await
        .map_err(super::llm_fallback::map_llm_error)?;

        let v: serde_json::Value =
            serde_json::from_str(&text).map_err(|e| DecisionError::Parse(e.to_string()))?;
        DecisionResponse::from_value(v)
    }

    fn model_name(&self) -> &str {
        &self.cfg.model
    }
}
```

```rust
fn map_decision_err(e: DecisionError) -> PyErr {

/// 工厂：按 config["mode"] 构造决策后端
///
/// mode = "stub"：无额外字段
/// mode = "replay"：需 "fixtures"（JSONL 路径）
/// mode = "http"：需 base_url / api_key / model，可选 timeout_secs / max_retries
#[pyfunction]
pub fn make_decision_backend(config: &Bound<'_, PyDict>) -> PyResult<PyDecisionBackend> {
    let v: serde_json::Value = pythonize(config.py(), config.as_any())?;
    let mode = v
        .get("mode")
        .and_then(|x| x.as_str())
        .unwrap_or("stub");

    let inner: Arc<dyn DecisionBackend> = match mode {
        "stub" => Arc::new(StubDecisionBackend::new()),
        "replay" => {
            let path = v
                .get("fixtures")
                .and_then(|x| x.as_str())
                .ok_or_else(|| pyo3::exceptions::PyValueError::new_err("replay mode requires fixtures"))?;
            let backend = ReplayDecisionBackend::from_jsonl(&PathBuf::from(path))
                .map_err(|e| pyo3::exceptions::PyValueError::new_err(e.to_string()))?;
            Arc::new(backend)
        }
        "http" => {
            let get = |key: &str| -> PyResult<String> {
                v.get(key)
                    .and_then(|x| x.as_str())
                    .map(str::to_string)
                    .ok_or_else(|| pyo3::exceptions::PyValueError::new_err(format!("http mode requires {key}")))
            };
            let cfg = SdmHttpConfig {
                base_url: get("base_url")?,
                api_key: get("api_key")?,
                model: get("model")?,
                timeout_secs: v.get("timeout_secs").and_then(|x| x.as_u64()).unwrap_or(30),
                max_retries: v.get("max_retries").and_then(|x| x.as_u64()).unwrap_or(3) as u32,
            };
            Arc::new(SdmHttpBackend::new(cfg).map_err(map_decision_err)?)
        }
        other => {
            return Err(pyo3::exceptions::PyValueError::new_err(format!(
                "unknown decision backend mode: {other}"
            )));
        }
    };

    let runtime = tokio::runtime::Runtime::new()
        .map_err(|e| pyo3::exceptions::PyRuntimeError::new_err(e.to_string()))?;
    Ok(PyDecisionBackend {
        inner,
        runtime: Arc::new(runtime),
    })
}

/// 从 Python state/questions 两个 dict 构造 DecisionRequest
fn parse_request<'py>(
    py: Python<'py>,
    state: &Bound<'py, PyAny>,
    questions: &Bound<'py, PyAny>,
) -> PyResult<DecisionRequest> {
    let state_v: serde_json::Value = pythonize(py, state)?;
    let questions_v: serde_json::Value = pythonize(py, questions)?;
    let combined = serde_json::json!({"state": state_v, "questions": questions_v});
    serde_json::from_value(combined)
        .map_err(|e| pyo3::exceptions::PyValueError::new_err(e.to_string()))
}

/// CascadeDecision → Python dict
fn decision_to_dict<'py>(py: Python<'py>, d: &crate::decision::types::CascadeDecision) -> PyResult<Bound<'py, PyDict>> {
    let dict = PyDict::new(py);
    dict.set_item("action", d.action.as_str())?;
    dict.set_item(
        "source",
        match d.source {
            DecisionSource::SdmDirect => "sdm_direct",
            DecisionSource::Fallback => "fallback",
        },
    )?;
    dict.set_item("confidence", d.confidence)?;
    let probs = PyDict::new(py);
    for (k, val) in &d.probabilities {
        probs.set_item(k, *val)?;
    }
    dict.set_item("probabilities", probs)?;
    match &d.fallback_reason {
        Some(r) => dict.set_item("fallback_reason", r)?,
        None => dict.set_item("fallback_reason", py.None())?,
    }
    match &d.sdm_usage {
        Some(u) => {
            let ud = PyDict::new(py);
            ud.set_item("input_tokens", u.input_tokens)?;
            ud.set_item("cost_usd", u.cost_usd)?;
            dict.set_item("sdm_usage", ud)?;
        }
        None => dict.set_item("sdm_usage", py.None())?,
    }
    let subs = PyDict::new(py);
    for (k, val) in &d.sub_signals {
        subs.set_item(k, *val)?;
    }
    dict.set_item("sub_signals", subs)?;
    Ok(dict)
}

#[pymethods]
impl PyCascadeLayer {
    /// 用规则兜底构造级联层
    #[new]
    fn new(backend: &PyDecisionBackend, _fallback: &PyRuleFallback, config: &PyCascadeConfig) -> Self {
        let layer = SdmCascadeDecisionLayer::new(
            backend.inner.clone(),
            Arc::new(RuleFallback::new()) as Arc<dyn FallbackDecider>,
            config.inner,
        );
        Self {
            shared: Arc::new(layer),
            runtime: backend.runtime.clone(),
        }
    }

    /// 同步决策：state/questions 为 dict，返回结果 dict
    fn decide<'py>(
        &self,
        py: Python<'py>,
        state: &Bound<'py, PyAny>,
        questions: &Bound<'py, PyAny>,
    ) -> PyResult<Bound<'py, PyDict>> {
        let req = parse_request(py, state, questions)?;
        let d = self.runtime.block_on(self.shared.decide(&req));
        decision_to_dict(py, &d)
    }

    /// 异步决策：返回 awaitable，不阻塞 Python 事件循环
    fn decide_async<'py>(
        &self,
        py: Python<'py>,
        state: &Bound<'py, PyAny>,
        questions: &Bound<'py, PyAny>,
    ) -> PyResult<Bound<'py, PyAny>> {
        let req = parse_request(py, state, questions)?;
        let holder = self.shared.clone();
        future_into_py(py, async move {
            let d = holder.decide(&req).await;
            Python::attach(|py| decision_to_dict(py, &d).map(Bound::unbind))
        })
    }
}

    m.add_class::<PyRuleFallback>()?;
    m.add_class::<PyCascadeConfig>()?;
    m.add_class::<PyCascadeLayer>()?;
    Ok(())
}
```

```rust
/// 把 Python 侧 LLMBackend 适配为决策兜底（仅绑定层耦合具体 OpenAICompatBackend）
struct PyLlmFallbackAdapter {
    llm: Arc<TokioMutex<OpenAICompatBackend>>,
}

#[async_trait::async_trait]
impl FallbackDecider for PyLlmFallbackAdapter {
    async fn decide(
        &self,
        state: &serde_json::Value,
    ) -> Result<
        (crate::decision::types::Action, std::collections::BTreeMap<String, f64>, f64),
        DecisionError,
    > {
        let prompt = crate::decision::LlmFallback::default_template();
        let state_str = state.to_string();
        let vars = std::collections::HashMap::from([("state", state_str.as_str())]);
        let user = prompt.render_user(&vars);
        let messages = vec![
            Message::system(prompt.system_with_few_shot()),
            Message::user(user),
        ];
        let guard = self.llm.lock().await;
        let resp = guard
            .complete(&messages)
            .await
            .map_err(crate::decision::llm_fallback::map_llm_error)?;
        drop(guard);
        let content = resp
            .content
            .ok_or_else(|| DecisionError::Parse("llm empty".into()))?;
        parse_llm_content(&content)
    }
}
```
